## 4. 滚动回测与稳健性（阶段 C + debug 结论）

- cut 06-15：hit1 0.1285 / hit3 0.2454；cut 07-01：hit1 0.1363 / hit3 0.2267；cut 07-20：hit1 0.0922 / hit3 0.3981。
- 与默认 80/20 命中（0.36/0.66）差异巨大。
- Debug 结论（详见 `_rerun/debug_top1_diff.csv`、`final_default_run1/2.csv`）：
  - 同配置两次运行完全确定（Top1 零变化）；
  - default 与 cut06-15 测试集几乎相同（重叠 1,035/1,035）、候选池相同、推荐覆盖相同；
  - 仅训练差 8 节点（6 ant + 2 IDC，21 行账，0.26%），却使 71% 节点 Top1 翻盘（733/1,035），其中 default 对而 cut 错的 246 里 245 是 ant；
  - 机制：Top1 来自“相似邻居真实跑过业务”候选；ant 画像缺失使邻居高度集中，训练少那几个关键 ant 即替换大量 ant 测试节点的邻居→候选业务集变→Top1 翻盘。**非随机、非实现 bug，而是“相似邻居候选法”对训练节点构成敏感（在 ant 聚类上放大）**。
- 结论：默认 0.36/0.66 命中不是普适稳健值，波动由候选结构敏感造成；交付须披露。
