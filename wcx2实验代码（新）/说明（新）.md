# wcx2 实验代码目录说明（新）

本目录存放迭代过程中**一次性实验脚本**，用于产出对应（新）文档中的结论。

## 使用限制（重要）

- 脚本内**硬编码了本地路径**（如 `D:\machine-test-local\wcx`、本地 `_rerun`/临时目录），
  **不保证在其它机器直接运行**；
- 依赖本地已生成的数据产物（`recent_month_large_*（新）` 等，不入库）；
- 因此本目录**不是复现入口**，仅作**审计留痕**。

## 真正采用的改动在哪

- **采用的模型改动**在仓库根的 `v5_hybrid_recommendation.py`（参数化、可移植）：
  - `V5_RECENCY_HALF_LIFE`（默认 7）
  - `V5_RECENCY_WEIGHT_CAP`（默认 1.5）
- 复现请走仓库 README 的正式流程 + `采用配置（新）.md`，不要依赖本目录脚本。
