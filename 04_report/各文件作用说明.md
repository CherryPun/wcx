# 各文件作用说明（按目录）

> 目的：说明仓库内每个文件“是什么、干什么、和谁有关”。所有可复现数字来自
> `run_verify_all.py`，数据字段见 `05_shared_data/DATA_README.md`。仅保留主版与依据；
> 无效/实验性方案结论见《关键数字口径稿》，脚本与中间产物已归档不在此仓库。

## 根目录

| 文件 | 作用 | 与谁相关 |
|---|---|---|
| `README.md` | 项目总览：定位、目录关系、主结果、数据来源、复现路径、严谨性说明 | 全部 |
| `requirements.txt` | 运行依赖（pandas/numpy/scipy/scikit-learn/xgboost） | 所有脚本 |
| `.gitignore` | 排除大数据（`05_shared_data/*.csv`）、`_rerun/`、缓存、凭据 | 仓库 |
| `run_verify_all.py` | 一键复现校验：重跑 01 诊断、01 时间外、02 主版、HTML 生成并核对关键数字 | 01/02 |

## 01_temporal_validation（结论的事实依据）

| 文件 | 作用 | 输入→输出 |
|---|---|---|
| `stage_p0_temporal.py` | 时间外切分（按节点引入日前80/20）+ 平台利润资格门槛的 XGB 评估 | 数据→`final_top3_temporal_metrics.json` 等（`_rerun`） |
| `stage_diag_coldstart.py` | 冷启动五基线对比（全局热度/业务先验/分段/KNN/XGB） | 数据→`coldstart_baseline_metrics.json` |
| `coldstart_baseline_metrics.json` | 冷启动基线结果快照（正式） | 由上面脚本生成 |
| `final_top3_temporal_metrics.json` | 时间外无候选收窄结果快照（正式） | 由 stage_p0 生成 |

## 02_main_recommendation（主版 v1）

| 文件 | 作用 | 说明 |
|---|---|---|
| `stage_e2e.py` | **主版端到端**：相似节点候选 + 矿主结算主序 + 平台/容量软降权 + 带宽辅助分 | 全仓核心（238 行），数据→`final_top3_e2e.csv`、`e2e_metrics.json`、HTML |
| `final_top3_e2e.csv` | 主版结果：5171 节点 Top1~3 + 矿主结算/平台利润 | 供 HTML/口径稿/纠偏使用 |
| `e2e_metrics.json` | 主版指标（命中/利润为正率/金额 WAPE） | 复现校验比对对象 |
| `build_final_html.py` | 由 `final_top3_e2e.csv` 生成 `06_html/全节点推荐_最终版.html`（含业务名）；并读 `05_shared_data/cur7d_map.csv` 渲染“当前在跑(近7天实际)”对照列 | 输入 02+05 |
| `build_distribution_chart.py` | 生成推荐分布可视化（Top10 条形 + 占比环状，纯 SVG） | 输入 02 |
| `__pycache__/stage_e2e*.pyc` | 运行缓存（不入库） | 忽略 |
